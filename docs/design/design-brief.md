# Project Brief: NEURAL_LINK File Management System

## 1. Project Overview
**NEURAL_LINK** is a high-security, high-performance file management application designed with a "Cybernetic Core" aesthetic. It targets power users, security operators, and individuals who require a tactile, high-tech interface for managing encrypted data streams and secure storage volumes.

## 2. Design Vision: "Cybernetic Core"
The visual identity is defined by a dark-mode obsidian foundation, high-contrast neon accents (Primary: #00f2ff), and glassmorphic UI elements.
- **Typography**: Inter for UI controls; Monospace (Data Mono) for system logs and terminal views.
- **Atmosphere**: Futuristic, industrial, and high-fidelity.
- **Key Motifs**: Glowing borders, scan-line textures, holographic progress indicators, and biometric authentication UI.

## 3. Core Functional Modules
The application is currently composed of four primary interface nodes:

### A. System Dashboard ({{DATA:SCREEN:SCREEN_6}})
- **Purpose**: Global overview of system health and storage distribution.
- **Features**: 
    - Holographic "Visual Drive" utilization chart.
    - Real-time "System Logs" feed for authentication and traffic monitoring.
    - Interactive "System Nodes" for rapid navigation to Root, Encrypted, and Media sectors.

### B. Secure Vault ({{DATA:SCREEN:SCREEN_5}})
- **Purpose**: Access point for high-priority, encrypted data.
- **Features**:
    - "Quantum-7" encryption status monitoring.
    - Biometric (fingerprint) authentication trigger.
    - Grid-based secure directory and payload navigation.

### C. Active Uplink ({{DATA:SCREEN:SCREEN_4}})
- **Purpose**: Management of live data transfers and network bandwidth.
- **Features**:
    - "Glitch-style" dual-tone progress bars.
    - Live bandwidth telemetry (Upload/Download).
    - Individual transfer controls (Suspend, New Transfer).

### D. File Terminal ({{DATA:SCREEN:SCREEN_2}})
- **Purpose**: Deep-level file inspection and critical system actions.
- **Features**:
    - Monospace code/log viewer with line numbering.
    - Metadata inspector (Hash validation, timestamps, permissions).
    - Critical actions: Decrypt and Purge.

## 4. Technical Requirements
- **Platform**: Initial release optimized for Mobile (Portrait).
- **Interactions**: Haptic feedback on biometric triggers, smooth transitions between nodes via the "BottomNavBar," and backdrop-blur effects on elevated layers.
- **Security**: Mock-up implementation of Level 4 access requirements and SHA-256 hash validation.

## 5. Next Steps
- Expand to Desktop (Landscape) orientations.
- Implement interactive terminal command input.
- Develop "Network Map" visualization for node-to-node traffic.
